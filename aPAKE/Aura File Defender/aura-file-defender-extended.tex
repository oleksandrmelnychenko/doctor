\title{Policy-Indexed Authorization for Canonical Reconstruction and
Fail-Closed Delivery of Untrusted Media}

\author{Oleksandr Melnychenko\texorpdfstring{\,\orcidlink{0000-0001-8565-7092}}{}\texorpdfstring{\corref{cor1}}{}}
\ead{melnychenko@khmnu.edu.ua}
\cortext[cor1]{Corresponding author.}
\address{Khmelnytskyi National University, Khmelnytskyi, Ukraine}

\begin{abstract}
Authenticated channels can deliver media that remain ambiguous or unsuitable
for local use. We present a transport-independent, policy-indexed method that
reconciles filename, declared type, and bounded byte evidence; selects one
source profile; enforces the required structural or semantic reconstruction;
validates the complete candidate on a code path separate from construction;
and publishes only clean, non-overwriting output. Conditional canonical-
delivery and fixed-witness monotonicity results make authorizing-parser,
construction, and filesystem assumptions explicit. The Rust implementation
covers image, audio, ISO base media, and WebM profiles. In a bounded experiment,
fixture-derived actions matched for 104 generated benign or inert-unsupported
records, measuring fixture--policy consistency rather than independent ground
truth. A later versioned rehearsal completed differential, fidelity, paired-
ablation, 14-case fault, and available-regeneration checks, but used an under-
budget generated corpus. No public source received independent admission, and
the prescribed fuzzing and controlled-performance schedules were not run on a
dedicated host. Consequently, \(G_{\mathrm{sci}}\) and release eligibility
remain false: the retained observations support the method and finite-run
traceability, not population efficacy, malware detection, capacity, or release.
\end{abstract}
