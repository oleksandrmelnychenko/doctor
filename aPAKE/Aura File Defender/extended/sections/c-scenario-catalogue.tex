\section{Safe Scenario Catalogue}
\label{app:scenario-catalogue}

This catalogue defines non-operational carrier tests. Each identifier expands
to format and boundary instances while retaining its S0--S7 stratum.

Executable-shaped material uses an ASCII sentinel, optional format magic, an
inert length, and deterministic padding. It contains no code, command, address,
credential, persistence action, or exploit. Decoder-control-flow claims require
S7 evidence instead.

\subsection{Scenario expansion and audit trail}
\label{subsec:scenario-expansion}

Each record names its scenario and records generator commit, base digest,
profile, element path, changed values, seed, and expected reason. The artifact
is hashed and not regenerated during measurement.

Coverage counts scenario-format pairs. An uninstantiated row is a gap, not a
passing zero-event test.
