\small
\raggedright
Git-safe implementation and evidence records are retained in the private
\href{https://github.com/oleksandrmelnychenko/ecliptix-file-defender}
{Ecliptix File Defender repository} and four immutable anchors: the
\href{https://github.com/oleksandrmelnychenko/ecliptix-file-defender/tree/823a5ec7a0dd56a5ba1c12a5aa45c77a4bff71c0/docs/research/rehearsals/20260720T130631Z-server-experiment-dcd6e114d21a}
{bounded server experiment}, the
\href{https://github.com/oleksandrmelnychenko/ecliptix-file-defender/releases/tag/evidence-public-source-pilot-20260724T215601Z-39bf19f1d17b-c44fdc45}
{public-source pilot prerelease}, the
\href{https://github.com/oleksandrmelnychenko/ecliptix-file-defender/releases/tag/evidence-public-source-review-handoff-20260725T231947Z-8aa55ef}
{offline reviewer-handoff prerelease}, and the
\href{https://github.com/oleksandrmelnychenko/ecliptix-file-defender/tree/a7d4e4c0425a0265d3438d6a2474acc72de0933d/docs/research/rehearsals/20260727T151107Z-50e0c8f-controlled-readiness}
{controlled-readiness record}. The linked records retain commit identities,
manifests, checksums, per-record results, gate matrices, and attestations; the
prereleases retain the large archives. They are release-ineligible and contain
no independent admission signature. If private at publication, the archives
require a persistent public or controlled-access deposit.
